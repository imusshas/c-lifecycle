# C LifeCycle

This repository demonstrates the four main stages of converting a C source file into an executable program:

```text
hello.c
   ↓
Preprocessor
   ↓
hello.i
   ↓
Compiler
   ↓
hello.s
   ↓
Assembler
   ↓
hello.o
   ↓
Linker
   ↓
Executable
```

The example source file is assumed to be:

```text
hello.c
```

---

## Run on Windows

The following commands assume GCC is installed through MSYS2/MinGW-w64.

### Preprocessor

- **Run:** `gcc -E hello.c -o hello.i`
- **View:** `cat hello.i`

The View command shows the preprocessed C source code after header inclusion, macro expansion, and conditional preprocessing.

### Compiler

- **Run:** `gcc -S hello.i -o hello.s`
- **View:** `cat hello.s`

The View command shows the assembly code generated by the compiler.

### Assembler

- **Run:** `gcc -c hello.s -o hello.o`
- **View:** `objdump -d hello.o`

The View command shows the machine instructions stored inside the object file.

### Linker

- **Run:** `gcc hello.o -o hello.exe`
- **View:** `objdump -d hello.exe`

The View command shows the machine instructions inside the final Windows executable.

Run the executable with:

```bash
./hello.exe
```

## Run on Mac

The following commands work on Apple Silicon Macs such as M1, M2, M3, and M4.

### Preprocessor

- **Run:** `gcc -E hello.c -o hello.i`
- **View:** `cat hello.i`

The View command shows the preprocessed C source code after header inclusion, macro expansion, and conditional preprocessing.

### Compiler

- **Run:** `gcc -S hello.i -o hello.s`
- **View:** `cat hello.s`

The View command shows the ARM64 assembly code generated by the compiler.

### Assembler

- **Run:** `gcc -c hello.s -o hello.o`
- **View:** `otool -tvV hello.o`

The View command shows the machine instructions stored inside the Mach-O object file.

### Linker

- **Run:** `gcc hello.o -o hello`
- **View:** `otool -tvV hello`

The View command shows the machine instructions inside the final Mach-O executable.

Run the executable with:

```bash
./hello
```
